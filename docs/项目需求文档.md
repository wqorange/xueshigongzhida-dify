# 项目需求文档 — 学工智答

> 基于《学工智答项目策划书（7月9日最终版）》整理 · 中原工学院软件学院

---

## 1. 背景与痛点

当前高校学生事务中心日均咨询量超过 **400 人次**，但仅约 **60%** 的基础需求能得到及时响应，**30%** 的咨询需要等待超过 24 小时。某省属高校调研显示：

- 近 **60%** 学生反映线上服务响应延迟问题突出
- 新生因政策理解偏差导致的重复咨询占绝大部分
- 听障学生依赖人工手语翻译时，咨询等待时间平均超过 **2 小时**
- 视障学生通过文本获取政策信息的效率不足普通学生的 **1/3**

## 2. 目标用户

| 用户群体 | 典型场景 | 核心诉求 |
|---|---|---|
| 全日制本科生 | 奖助学金申请、家庭经济困难认定、助学贷款 | 7×24 即时响应、权威准确、少走弯路 |
| 研究生 | 毕业手续、学籍异动、转专业 | 流程清晰、步骤明确、材料齐全 |
| 新生 | 入学指南、党员发展、团员发展 | 入门友好、术语易懂、分类引导 |
| 学工人员 | 减轻事务性重复咨询负担 | 工作量减少 60%+、聚焦复杂个性化问题 |
| 特殊群体 | 视障 / 听障 / 国际学生 | 语音交互、多语言、结构化输出 |

## 3. 功能需求（MVP → V2 二期）

### MVP 功能（当前已实现）

| # | 功能 | 说明 | Dify 实现 |
|---|---|---|---|
| F1 | 文本问答 | 用户文字提问，系统实时返回权威答案 | ✅ LLM 主回答节点 |
| F2 | 多轮对话 | 支持上下文关联，连续对话中理解用户意图 | ✅ LLM memory 配置 |
| F3 | 查询优化 | 将用户口语化提问转换为标准政策术语，提升检索召回率 | ✅ LLM 3 查询优化节点 |
| F4 | 知识检索 | 混合检索（向量 + 关键词）+ qwen3-rerank 重排序 | ✅ 知识检索节点，Top-K=4 |
| F5 | 回答规范 | 严禁照抄原文，要求"理解后用自己的话回答" | ✅ LLM 主回答提示词（3084 字符） |
| F6 | 助学金/奖学金概念区分 | 强制回答规则，禁止混淆助学金（看家庭经济困难）和奖学金（看成绩） | ✅ 提示词第 6 节"强制规则" |
| F7 | 回答后推荐 | 回答后主动推荐 2-3 个相关问题 | ✅ suggested_questions_after_answer |
| F8 | 语音转文字 | 支持学生语音输入 | ✅ speech_to_text 开启 |
| F9 | 建议问题分类引导 | 开场推荐 3 条高频问题 | ✅ suggested_questions |
| F10 | 边界安全 | 拒绝非政策类咨询，敏感群体引导 | ✅ 提示词第 4-5 节 |
